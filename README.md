# Excel Bike Sales Dashboard

An interactive Excel dashboard built to analyze global bike sales performance, track multi-year revenue trends, and segment customer demographics.

## Project Overview
This project transforms raw transactional sales records into a polished executive dashboard using advanced Excel analysis tools. It is designed to provide actionable business insights and support data-driven decision-making.

## Key Workflow & Features
- **Data Cleaning & Preparation:** Standardized raw sales records in a dedicated `Working Sheet`, resolved field alignment errors, formatted currency values, and removed duplicate entries.
- **Pivot Table Analysis:** Constructed four core Pivot Tables to evaluate key revenue drivers:
  1. **Revenue by Age Group:** Compares purchasing volume across Youth, Young Adults, Adults, and Seniors.
  2. **Revenue by Year:** Tracks annual sales performance and growth trends from 2011 to 2016.
  3. **Revenue by Country:** Breaks down regional revenue across key international markets.
  4. **Revenue by Product Category:** Identifies top-performing bike types and accessories.
- **Interactive Dashboard & Slicers:** Designed a centralized `Dash Board` tab featuring customized Pivot Charts connected dynamically via `Country` and `Year` Slicers (utilizing Report Connections for real-time cross-filtering across all visuals).

## Tools & Skills Used
- **Microsoft Excel:** Data Cleaning, Pivot Tables, Pivot Charts, Slicers, Report Connections
- **GitHub:** Portfolio Documentation & Version Control

## How to View
1. Download the `Bike_Sales_Dashboard.xlsx` file from this repository.
2. Open the workbook in Microsoft Excel to interact with the Slicers and explore the underlying Pivot Tables and raw data tabs.
